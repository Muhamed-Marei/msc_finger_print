# ADR 0001: Adopt the docs harness

- Date: {{DATE}}
- Status: Accepted
- Supersedes: —

## Context
{{PROJECT}} is expected to run past the point where anyone remembers why it was built
this way. Work is carried out across sessions and across people, with AI agents writing
a large share of the code. Chat history and memory are lost; the repository is not.

## Decision
The `docs/` tree defined by the docs-harness skill is the project's persistent memory.
Phases own feature slices. `AGENTS.md` is the only always-loaded file and routes to
everything else. Architecture, rules, and decisions are human-owned and append-only
where marked. Every document exists in Arabic and English, with sync machine-verified.

## Alternatives rejected
| Option | Why not |
|---|---|
| Wiki / Notion outside the repo | Drifts from code immediately; agents cannot read it during a task. |
| One large context file | Load-bearing lines get lost in the middle; cost rises with every session. |
| Feature-first folders with no phases | A feature's chronology scatters; "what shipped when" becomes unanswerable. |
| English-only docs | Client-facing and government deliverables require Arabic; translating late produces two divergent truths. |

## Consequences
- Documentation maintenance is real work, budgeted at roughly 10–15% of effort.
- `validate.py` must pass before a phase is closed.
- Arabic mirrors carry a `source_sha`; a stale mirror fails the docs check.
- An agent may not edit `architecture.md`, `rules.md`, or `decisions/`.

# سجل قرار معماري 0001: اعتماد منظومة التوثيق

- التاريخ: {{DATE}}
- الحالة: معتمد
- يحل محل: —

## السياق
من المتوقع أن يستمر {{PROJECT}} إلى ما بعد النقطة التي ينسى فيها الجميع سبب بنائه بهذه الطريقة.
يجري العمل عبر جلسات وأشخاص متعددين، ويكتب وكلاء الذكاء الاصطناعي نسبة كبيرة من الكود.
سجل المحادثات يضيع، أما المستودع فلا.

## القرار
شجرة `docs/` المعرَّفة في هذه المنظومة هي الذاكرة الدائمة للمشروع.
المراحل تحتوي شرائح الميزات. ملف `AGENTS.md` هو الملف الوحيد المحمَّل دائمًا ويوجّه إلى ما عداه.
المعمارية والقواعد والقرارات ملك للبشر، وبعضها يُضاف إليه ولا يُعدَّل.
كل وثيقة موجودة بالعربية والإنجليزية، والتزامن مُتحقَّق منه آليًا.

## البدائل المرفوضة
| البديل | سبب الرفض |
|---|---|
| ويكي أو Notion خارج المستودع | ينفصل عن الكود فورًا، ولا يستطيع الوكيل قراءته أثناء المهمة. |
| ملف سياق واحد ضخم | تضيع الأسطر الجوهرية في المنتصف، وترتفع التكلفة مع كل جلسة. |
| تنظيم بالميزات بلا مراحل | يتشتت التسلسل الزمني للميزة ويصعب معرفة ما صدر ومتى. |
| توثيق بالإنجليزية فقط | المخرجات الحكومية والعميلية تتطلب العربية، والترجمة المتأخرة تنتج حقيقتين متعارضتين. |

## النتائج
- صيانة التوثيق عمل حقيقي يُقدَّر بنحو 10–15% من الجهد.
- يجب اجتياز `validate.py` قبل إغلاق أي مرحلة.
- كل نسخة عربية تحمل `source_sha`، والنسخة القديمة تُسقط فحص التوثيق.
- يُمنع على الوكيل تعديل `architecture.md` أو `rules.md` أو `decisions/`.
