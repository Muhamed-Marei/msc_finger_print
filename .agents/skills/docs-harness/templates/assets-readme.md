# Brand Assets — ملفات الهوية

Binaries only. No specification text below this file — that lives in `../identity.md`
and `../design-tokens.md`.

## Naming
`{{PROJECT}}-<asset>-<variant>-<lang>.<ext>` — e.g. `logo-primary-ar.svg`, `logo-mono-en.svg`

## Rules
- Vector source (`.svg`, `.ai`) MUST be committed alongside every raster export.
- Fonts MUST NOT be committed unless the licence permits redistribution. Record the licence here.
- Exports are regenerated from source; a raster with no source is orphaned and MUST be replaced.
