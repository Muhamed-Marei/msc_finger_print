## Core Patterns

**1. Intent-Driven UI (Machine Experience)**
Proactive insights over passive navigation.
```dart
PredictiveInsightCard(
  insight: '3 tasks at risk',
  actionLabel: 'Review',
  onActionTap: () => reviewTasks(),
)
```

**2. Tactile Maximalism ("Squishy")**
Physics-based interaction <100ms.
```dart
SquishyButton(
  child: Text('Launch'),
  onPressed: () => launch(),
)
```

**3. Glassmorphism 2.0**
Frosted overlays with high legibility.
```dart
GlassCard(
  blur: 15,
  opacity: 0.15,
  child: Content(),
)
```

**4. Semantic Tokens**
Never hardcode colors.
```dart
// ❌ Color(0xFF2196F3)
// ✅ DesignTokens.brand.primary(context)
Container(color: DesignTokens.surface.elevated(context))
```
