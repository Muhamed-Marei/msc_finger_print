# Compliance Matrix — Requirements Traceability Template

> **Purpose:** Map every RFP requirement to its response. Acts as both response checklist and deal-intelligence tool.
> **Process:** "Shred" the RFP — strip line by line, extracting requirements via operative verbs: **shall, must, will, provide**.

## Priority Classification

| Priority | Definition | Action |
|:---------|:-----------|:-------|
| **Critical** | Security certifications, legal indemnifications, mandatory administrative docs | Address FIRST — failure = automatic disqualification |
| **High** | Core technical requirements, scoring-weighted evaluation criteria | Address in first draft cycle |
| **Medium** | Supporting requirements, nice-to-haves | Address after critical/high items secured |
